옵션

희석 배수는 농축한 시료면 1보다 작게 넣음 (10배 농축 = 0.1). 챔버·부피·희석 값은 시료를 저장해도 그대로 남고, 저장된 행에는 그때 값이 같이 기록됨.

홈 화면에 추가하면 주소창 없이 전체 화면으로 열리고 인터넷 없이도 됨. 아이폰: Safari 공유 버튼 → 홈 화면에 추가. 안드로이드: Chrome 메뉴 → 홈 화면에 추가.

저장된 시료

계수와 저장된 시료는 이 기기의 이 브라우저에만 저장됨. 브라우저 데이터를 지우면 같이 사라지니 실험이 끝나면 엑셀로 내보낼 것. 세는 중인 시료도 마지막 행으로 포함됨. SD는 표본 표준편차(n−1).
